# Study CoCo

GitHub Pagesで公開できる、ブラウザ内保存型の学習計画PWAです。

## 公開ファイル

ZIP内の `StudyPilot` フォルダを開き、その中身（`index.html`、`app.js`、`style.css`、`manifest.webmanifest`、`service-worker.js`、アイコン2つ）をGitHubリポジトリ直下にアップロードしてください。

## 学習計画の作り方

このバージョンはOpenAI APIなどの外部AIには接続しません。入力した課題を、次の固定順序で予定に組み込みます。

1. 提出課題
2. 月間の課題
3. 年間の課題
4. 模試・定期テスト対策

月間・年間の課題は、それぞれの一覧に登録した未完了項目が計画作成時に自動で候補になります。計画内で完了チェックを付けると、元の月間・年間リストにも完了が反映されます。完了済みの長期課題は次回の計画候補から外れます。

- 就寝時刻から開始時刻までの時間を計算
- 食事・入浴時間を確保
- 学習タスクの間に10分休憩を配置
- タスクの種類が同じ優先区分内では、思考系を前、暗記系を後ろに配置
- コッコ隊長の吹き出しをタップするとセリフが順番に切り替わる
- 通常プランの達成状況を記録

計画作成には、提出課題、月間課題、年間課題、模試・テスト対策のいずれかを登録してください。

## 保存と注意

- 学習データは同一サイト・同一ブラウザのlocalStorageに保存されます。
- ブラウザのサイトデータを削除すると保存内容も消えるため、定期的にJSONバックアップを取ってください。
- 旧版のプロフィール情報は、時間計算に使う就寝時刻・食事時間・入浴時間だけを引き継ぎます。
- 旧版の最低限プランは廃止されます。以前の最低限プラン達成による +5 ポイントは新しいランク集計に含めません。
- GitHub Pages上の公開サイトに個人情報やパスワードを入力しないでください。

## 更新

同じGitHubリポジトリの同名ファイルを上書きしてCommitします。公開URLはリポジトリ名を変えない限り変わりません。
