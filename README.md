# Study CoCo

GitHub Pagesで公開できる学習計画PWAです。既存のStudyPilotリポジトリを使う場合は、ZIPを解凍し、StudyPilotフォルダ内のファイルを既存ファイルに上書きしてください。公開URLとlocalStorageキーは維持されます。

- `index.html` などをリポジトリの公開ルートへ配置
- `main` / `/(root)` でGitHub Pagesを公開
- iPhoneではSafariの共有メニューからホーム画面に追加
- 学習記録は同じブラウザ内に保存。定期的にJSONバックアップを推奨

コッコ隊長の会話機能はオフラインの定型応答で、AI相談機能ではありません。
