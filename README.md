# Study CoCo

GitHub Pagesで公開できる、ブラウザ内保存型の学習計画PWAです。

## 公開ファイル

リポジトリ直下に `index.html`、`app.js`、`style.css`、`manifest.webmanifest`、`service-worker.js`、`icon-192.png`、`icon-512.png` を配置してください。

## 学習計画の作り方

このバージョンはOpenAI APIなどの外部AIには接続しません。ブラウザ内のJavaScriptが入力内容をもとにルールベースで計画を作ります。

- 就寝時刻から開始時刻までの時間を計算
- プロフィールの食事・入浴時間を確保
- タスク間に休憩を配置
- 入力された具体的なタスク、提出課題、テスト内容を候補にする
- 優先度の高いタスクを先に配置
- 暗記キーワードを含むタスクは後ろ、思考系キーワードを含むタスクは前に寄せる
- タスクごとに固有IDを割り当て、同じ名前でもチェック状態を独立させる

具体的なタスク欄は1行に1タスクで入力します。行頭に `[高]` `[中]` `[低]` を付けると、そのタスクだけ優先度を指定できます。指定がない場合は「重点タスクの優先度」が使われます。

例：
- `[高] 数学：Focus Goldの微分の例題を3問解く`
- `[中] 英語：英単語帳Unit 5をテストする`
- `[低] 古文：助動詞の活用表を確認する`

## 保存と注意

- 学習データは同一サイト・同一ブラウザのlocalStorageに保存されます。
- ブラウザのサイトデータを削除すると保存内容も消えるため、定期的にJSONバックアップを取ってください。
- GitHub Pages上の公開サイトに個人情報やパスワードを入力しないでください。

## 更新
